Introducción

Este sistema permite conectarse dinámicamente a múltiples motores de base de datos. El objetivo es permitir conexiones de forma rapida y sencilla, para descargar reportes completos y precisos de cualquier tabla de la base de datos. ademas de poder ver la estructura de la base de datos con sus tablas y columnas, por lo que se convierte en una herramienta muy util para el administrador de la base de datos y para el usuario que necesite obtener informacion de la base de datos. Esta se puede descargar en formato Excel y CSV (Json Proximamente).

Recomendación: Crear un usuario previamente en la base de datos, con permisos limitados a solo lectura de las tablas que se vayan a utilizar.

SQL Server

SQL Server utiliza bases de datos, logins y usuarios separados. Primero se crea el login del servidor y luego el usuario dentro de la base de datos.

Herramienta gráfica recomendada: SQL Server Management Studio (SSMS)

Creación mediante interfaz gráfica (SSMS)

  • 1. Abrir SQL Server Management Studio
  • 2. Click derecho en "Databases"
  • → New Database
  • 3. Nombre:
  • → EmpresaDB
  • 4. Security
  • → Logins
  • → New Login
  • 5. Crear usuario:
  • → empresa_user
  • 6. Asignar contraseña
  • 7. En "User Mapping"
  • → seleccionar EmpresaDB
  • 8. Activar:
  • → db_datareader
  • → db_datawriter
  • → db_owner

    • Creación mediante SQL

    CREATE DATABASE EmpresaDB; GO CREATE LOGIN empresa_user WITH PASSWORD = '123456'; GO USE EmpresaDB; GO CREATE USER empresa_user FOR LOGIN empresa_user; GO ALTER ROLE db_owner ADD MEMBER empresa_user; GO

    MySQL

    MySQL trabaja principalmente con bases de datos y usuarios asociados al host.

    Herramienta gráfica recomendada: MySQL Workbench

    Creación mediante interfaz gráfica

  • 1. Abrir MySQL Workbench
  • 2. Schemas
  • → Create Schema
  • 3. Nombre:
  • → EmpresaDB
  • 4. Administration
  • → Users and Privileges
  • 5. Add Account
  • 6. Usuario:
  • → empresa_user
  • 7. Asignar contraseña
  • 8. En "Schema Privileges"
  • → agregar permisos sobre EmpresaDB

    • Creación mediante SQL

    CREATE DATABASE EmpresaDB; CREATE USER 'empresa_user'@'localhost' IDENTIFIED BY '123456'; GRANT ALL PRIVILEGES ON EmpresaDB.* TO 'empresa_user'@'localhost'; FLUSH PRIVILEGES;

    PostgreSQL

    PostgreSQL utiliza roles para manejar usuarios y permisos.

    Herramienta gráfica recomendada: pgAdmin 4

    Creación mediante interfaz gráfica

  • 1. Abrir pgAdmin
  • 2. Databases
  • → Create
  • → Database
  • 3. Nombre:
  • → empresadb
  • 4. Login/Group Roles
  • → Create
  • → Login Role
  • 5. Usuario:
  • → empresa_user
  • 6. Asignar contraseña
  • 7. En Privileges:
  • → activar permisos necesarios

    • Creación mediante SQL

    CREATE DATABASE empresadb; CREATE USER empresa_user WITH PASSWORD '123456'; GRANT ALL PRIVILEGES ON DATABASE empresadb TO empresa_user;

    Oracle

    Oracle trabaja principalmente con usuarios y esquemas. El esquema normalmente tiene el mismo nombre del usuario.

    Oracle maneja usuarios y esquemas de forma distinta a MySQL o SQL Server.
    Herramienta gráfica recomendada: Oracle SQL Developer

    Creación mediante interfaz gráfica

  • 1. Abrir Oracle SQL Developer
  • 2. Conectarse como SYSTEM
  • 3. Security
  • → Users
  • → Create User
  • 4. Usuario:
  • EMPRESA_USER
  • 5. Asignar contraseña
  • 6. Activar:
  • CONNECT
  • RESOURCE
  • 7. Asignar tablespace USERS

    • Creación mediante SQL

    CREATE USER EMPRESA_USER IDENTIFIED BY 123456; GRANT CONNECT, RESOURCE TO EMPRESA_USER; ALTER USER EMPRESA_USER QUOTA UNLIMITED ON USERS;

    Mensajes y Alertas

    ✅ Conexión Exitosa

    La conexión fue realizada correctamente.

    ❌ Credenciales Incorrectas

    Usuario o contraseña inválidos.

    ⚠ Timeout

    El servidor demoró demasiado en responder.

    🚫 Acceso Denegado

    El usuario no tiene permisos suficientes.

    Preguntas Frecuentes

    ¿Qué hace el modo administrativo?

    Permite explorar múltiples bases de datos dependiendo de los permisos del usuario.


    ¿La contraseña queda guardada?

    Debe almacenarse de forma segura y cifrada usando sesiones protegidas.
